STORYSIGHT V1
DETAIL SISTEM LENGKAP
Format: TXT

============================================================
1. KONSEP UTAMA SISTEM
============================================================

StorySight V1 adalah platform website pembelajaran bahasa Inggris melalui media cerita.

Fokus utama V1:
- User membaca cerita melalui PDF
- User menonton cerita melalui video
- User mengerjakan quiz setelah membaca/menonton
- Admin mengelola story, PDF, video, dan quiz
- Sistem menyimpan progress dan score user

Tagline konsep:
“Learn English Through Stories”

StorySight V1 dibuat sebagai MVP yang sederhana, cepat dikembangkan, namun tetap scalable untuk fitur AI dan interaktif di versi berikutnya.

============================================================
2. ROLE PENGGUNA
============================================================

A. Guest
Guest adalah pengunjung yang belum login.

Akses:
- Melihat landing page

User adalah pengguna utama platform.

Akses:
- Login dan register
- Melihat daftar story
- Membaca PDF story
- Menonton video story
- Mengerjakan quiz

Akses:
- Login admin
- Membuat story
- Upload PDF
- Upload video
- Membuat quiz
- Publish/unpublish story
- Melihat data user
- Melihat progress dan score user

11. SISTEM QUIZ
============================================================

Quiz muncul setelah user membaca PDF dan/atau menonton video.

Tujuan quiz:
- Menguji pemahaman cerita
- Menguji vocabulary
- Menguji listening comprehension
- Meningkatkan retention user

Jenis quiz V1:

A. Multiple Choice

Format:
- 1 pertanyaan
- 4 opsi jawaban
- 1 jawaban benar

Contoh:
What did Anna find?

A. A golden key
B. A red book
C. A blue bag
D. A small bird

B. Fill in the Blank

Format:
- User mengetik jawaban
- Sistem mencocokkan dengan jawaban benar
- Case insensitive

Contoh:
Anna found a small _____ key.

Correct answer:
golden

C. Matching

Format:
User mencocokkan kata dengan arti.

Contoh:
brave → berani
forest → hutan
lost → tersesat

D. Flashcard

Format:
- Card depan menampilkan kata
- Card belakang menampilkan arti
- User klik untuk flip card
- User bisa pilih “I know” atau “I don’t know”

Quiz engine flow:

User mulai quiz
→ Sistem tampilkan pertanyaan
→ User menjawab
→ User submit
→ Sistem hitung score
→ Sistem simpan hasil
→ Sistem tampilkan result

Scoring system:

Contoh:
10 soal
1 soal = 10 poin

Benar 8
Score = 80

Passing system:

passing_score = 70

Jika:

score >= 70

Maka:

status = PASSED

Jika:

score < 70

Maka:

status = FAILED

is_pdf_read = true

Ketika user selesai menonton video:

is_video_watched = true

Ketika user selesai quiz:

is_quiz_completed = true

Story dianggap selesai jika:

PDF selesai
AND
Video selesai
AND
Quiz selesai

Maka:

Sistem memvalidasi tipe file sebelum upload.
